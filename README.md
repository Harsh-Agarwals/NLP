# NLP & Deep Learning Implementations

A personal repository focused on implementing core **NLP**, **Deep Learning**, and **LLM** concepts from scratch to deeply understand how modern AI systems work internally.

Instead of only using high-level libraries, this repository explores the mathematics, architectures, training logic, and implementation details behind language models and neural networks.

---

# ⚡ What’s Covered

## Neural Networks & Deep Learning

* Feed Forward Neural Networks (FNN)

  * Implemented basic dense neural networks, backpropagation, activation functions, optimization, and training loops.

* Training Fundamentals

  * Gradient descent, loss functions, batching, regularization, dropout, normalization, and optimization techniques.

* GPU & CUDA Basics

  * Understanding GPU computation, tensor operations, and training acceleration concepts.
